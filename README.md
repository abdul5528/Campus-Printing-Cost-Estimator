## 📌 Project Description

StudySync is a responsive web-based Student Group Study Scheduler
developed using HTML, CSS, and JavaScript.

The application helps students organize study groups, schedule
academic study sessions, manage group members, and monitor
their study activities.

StudySync provides a simple and user-friendly dashboard where
students can create study groups, schedule meetings, track
upcoming sessions, and mark completed activities.

The application uses the browser's Local Storage to save
study groups and session information.

This project demonstrates the practical application of
front-end web development technologies in developing
an interactive academic scheduling application.

---

## 🎯 Project Objectives

The objectives of this project are:

1. To design a responsive student group study scheduling system.
2. To develop an application for creating and managing study groups.
3. To enable students to schedule academic study sessions.
4. To provide functionality for editing and deleting study sessions.
5. To implement a system for tracking upcoming and completed sessions.
6. To provide searching and filtering functionality.
7. To store study group and session information using Local Storage.
8. To develop a user-friendly interface for organizing academic activities.

## ✨ Application Features

### 1. Dashboard

The application provides a dashboard displaying:

- Total Study Groups
- Upcoming Study Sessions
- Completed Sessions
- Total Study Sessions

### 2. Study Group Management

Users can:

- Create new study groups
- Edit existing groups
- Delete study groups
- Add group members
- Assign subjects to study groups
- View group information

### 3. Study Session Scheduling

Users can:

- Schedule new study sessions
- Select a study group
- Choose a date and time
- Specify session duration
- Enter study location
- Add session descriptions
- Edit scheduled sessions
- Delete study sessions

### 4. Session Status Management

StudySync allows users to:

- View upcoming sessions
- Identify past sessions
- Mark sessions as completed
- Reopen completed sessions
- View completed study activities

### 5. Search and Filtering

Users can search for study sessions using:

- Session title
- Study group name
- Subject
- Study location

Sessions can also be filtered by status.

### 6. Dark and Light Mode

The application provides a theme toggle that allows
users to switch between dark and light modes.

### 7. Responsive Design

StudySync is designed to work on:

- Desktop computers
- Laptop computers
- Tablets
- Smartphones

### 8. Local Storage

The application saves study groups and sessions
using browser Local Storage.

Saved information remains available after refreshing
the page, provided the browser's website data
has not been cleared.

## 🚀 How to Run the Application

1. Download or clone the GitHub repository.
2. Extract the downloaded project if necessary.
3. Open the project folder.
4. Open `index.html` in a web browser.

Alternatively:

1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select "Open with Live Server".

The application will open in your browser.

## 📖 How to Use StudySync

### Creating a Study Group

1. Open the application.
2. Click "+ New Group".
3. Enter the group name.
4. Enter the subject or course.
5. Add a group description.
6. Enter group members separated by commas.
7. Click "Save Group".

### Scheduling a Study Session

1. Click "+ Schedule Session".
2. Enter the session title.
3. Select an existing study group.
4. Choose the study date.
5. Select the start time.
6. Choose the session duration.
7. Enter the study location.
8. Add a description.
9. Click "Save Session".

### Editing a Study Session

1. Navigate to Study Sessions.
2. Locate the session.
3. Click "Edit".
4. Modify the session information.
5. Click "Save Session".

### Completing a Study Session

1. Open Study Sessions.
2. Locate the session.
3. Click "Complete".
4. The session will be marked as completed.

### Deleting a Study Session

1. Locate the session.
2. Click "Delete".
3. Confirm the deletion.

### Searching for Sessions

1. Navigate to Study Sessions.
2. Enter a keyword in the search bar.
3. Matching sessions will be displayed.

## 💾 Data Storage

StudySync uses browser Local Storage.

The following storage keys are used:

- `studysync_groups`
- `studysync_sessions`
- `studysync_theme`

Data is stored locally in the user's browser.

The application does not require MySQL, PHP,
or an external database.

---

## ⚠️ Project Limitations

1. The application does not support user registration.
2. Study schedules are not synchronized across devices.
3. Group members cannot collaborate in real time.
4. Clearing browser storage can remove saved data.
5. The application does not currently send notifications.
6. Study groups and sessions are stored on one browser.
